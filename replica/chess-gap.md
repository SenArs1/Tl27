# Chessboard: competitor vs Stayra (2026-10-23)

Source: the public knowledge base of the original (9 articles about the
chessboard: overview, editing, moving rooms, quick moves, stays without a
through room, new-booking placement mode, check-in, check-out, booking
colours). Summary in our own words; the articles are linked at the bottom.

| Feature | Competitor | Stayra before | Stayra now (v5) |
| --- | --- | --- | --- |
| Rows = rooms by category, columns = days, half-day bars | yes | yes | yes |
| Count of free rooms in the category row | yes | yes | yes |
| Collapse a category (all collapsed = availability table) | yes | no | ✅ the category name collapses its rooms, remembered between visits |
| Today statistics above the chessboard (occupancy, arrivals/departures, in house, free, rooms) | yes | dashboard only | ✅ "Сегодня" strip: occupancy, arrivals (how many still expected), departures, in house, free, overdue, cleaning/repair |
| Filters that dim non-matching bookings (status, payment, source, tags) | yes | no | ✅ status, source, payment; tags — when tags exist |
| Booking search | separate search | journal only | ✅ search by name, phone, code, channel reference with highlight |
| Quick actions on click (check-in, move, check-out, payment, cancel, note) | panel with icons | card only | ✅ side panel: check-in with time and payment, check-out with remaining payment, undo check-out, payment, no-show, cancel, open card |
| Drag to another room **and** dates | yes, with "before/after" | room only | ✅ room and/or dates with a "Было/Станет" preview and confirmation |
| "Не изменять цену" when moving | checkbox | price always kept | ✅ checkbox; unticked — moved nights recalculated by the new category's rate |
| Move only before arrival | yes | — | ✅ dates — only before arrival; in house — room only, splitting from today |
| Partial move splits the bar | yes | yes (v3) | yes |
| "Без номера" row for through availability | yes, turquoise | yes | ✅ turquoise colour + "Распределить «Без номера»" button |
| New booking placement mode: auto / to "Без номера" | yes | auto only | ✅ choose above the chessboard |
| Colours: site/manual, channels, in house, checked out, overdue, unassigned, repair | yes | by status only | ✅ own palette, every text ≥ AA |
| Check-in with actual time and "заселить с оплатой" | yes | no | ✅ |
| Undo check-out with a reason | yes | no | ✅ the reason goes into the booking note |
| Early departure = date change | yes | yes (v3) | yes |
| Hourly bookings | yes | no | ❌ separate mode, not taken |
| Tags and notes with deadlines | yes | no | ❌ next — together with the booking card |
| Key issuing, receipts at the register | yes (integrations) | no | ❌ needs hardware/integrations |
